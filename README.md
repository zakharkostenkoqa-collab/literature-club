# Клуб української літератури та історії — хаб зустрічей

Односторінковий сайт без бекенду, без логіну, без бази даних. Весь контент —
у файлах `data/*.json`. HTML/CSS/JS не потребують перекомпіляції — просто
редагуєте JSON і зміни з'являються після наступного деплою (автоматично).

## Структура

```
index.html          — єдина сторінка з якорями (#home, #quiz, #archive, #leaderboard, #materials)
style.css            — стилі (архівний / бібліотечний дизайн)
script.js            — завантажує data/*.json і рендерить секції
data/topic.json       — тема поточної зустрічі
data/quiz.json        — питання вікторини
data/archive.json     — список минулих зустрічей + посилання
data/leaderboard.json — бали учасників по зустрічах
data/materials.json   — посилання на матеріали для читання
```

## Деплой на Cloudflare Pages (безкоштовно, ~5 хвилин)

1. Створіть публічний репозиторій на GitHub і залийте туди всі ці файли
   (можна прямо через веб-інтерфейс GitHub: "Add file" → "Upload files").
2. Зайдіть на [pages.cloudflare.com](https://pages.cloudflare.com), увійдіть
   через GitHub-акаунт.
3. "Create a project" → "Connect to Git" → оберіть свій репозиторій.
4. Build settings: **залиште все порожнім** (немає build command, немає
   build output directory — або вкажіть `/` як output directory). Це
   статичні файли, збірка не потрібна.
5. Deploy. Отримаєте посилання виду `https://your-project.pages.dev` —
   саме його й відкриваєте на кожному зідзвоні.

Кожен наступний коміт у гілку автоматично передеплоїться (і навіть покаже
preview-посилання для кожного pull request, якщо захочете спочатку
перевірити зміни перед публікацією).

### Альтернатива: GitHub Pages
Settings → Pages → Source: `main` branch, `/ (root)`. Посилання буде
`https://ваш-нікнейм.github.io/назва-репозиторію/`.

## Як оновлювати контент перед кожною зустріччю

Не потрібно нічого програмувати. Просто:

1. Зайдіть у репозиторій на GitHub.
2. Відкрийте потрібний файл у `data/` (наприклад `topic.json` для нової теми).
3. Натисніть іконку олівця ("Edit this file") прямо в браузері.
4. Змініть текст/дату/питання, збережіть коміт.
5. За кілька секунд Cloudflare Pages сам передеплоїть сайт.

Приклади того, що редагувати щомісяця:
- `data/topic.json` — нова тема, дата, вступ.
- `data/quiz.json` — нові питання вікторини.
- `data/archive.json` — додайте новий запис **зверху** списку з посиланням
  на запис зідзвону (Zoom cloud recording, YouTube unlisted тощо).
- `data/leaderboard.json` — впишіть бали учасників за цю зустріч (новий
  об'єкт у масиві `rounds`). Сума рахується автоматично.
- `data/materials.json` — посилання на статті/відео для наступної теми.

## Масштабування

Щоб додати нову секцію (наприклад "Цитата місяця" чи "Рекомендована книга"):
1. Додайте новий `data/....json` файл.
2. Додайте `<section id="...">...</section>` у `index.html` + пункт меню
   у `nav.tabs`.
3. Додайте функцію рендеру в `script.js` за прикладом наявних (`renderTopic`,
   `renderMaterials` тощо) і виклик у `DOMContentLoaded`.

Ніякого білд-інструменту, npm чи сервера — усе, що потрібно, це редагувати
текстові файли й комітити.

## Примітка щодо вікторини

Вікторина рахує бали локально в браузері кожного учасника (без збереження
на сервері). Після проходження кожен називає свій результат уголос —
ведучий вписує його в `data/leaderboard.json` після зустрічі. Це свідомий
компроміс заради нульової вартості й відсутності бази даних/акаунтів.
